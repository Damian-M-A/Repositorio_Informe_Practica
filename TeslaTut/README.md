## Cosas Importantes

* Las vistas se realizan a traves de qml
* La version de C++ cuanta con mas opciones, python esta un poco mas limitado en algunos aspectos
( un ejemplo son los mapas, python unicamente puede trabajar con osm)
* La logica se realiza mediante clases de python, luego se llaman y usan en main.py
* Componentes importantes de la clase:
    * Eventos = signal (se declaran fuera del  `__init__`)
    * Acciones = slot 
    * datos observables = property
